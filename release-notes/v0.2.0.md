# RoundTable v0.2.0

可视化圆桌会议插件正式版：**主持人 + 一圈专家 + 汇聚网关**，加上「针锋相对」红队评审。

## 新增（V0.2 主线）

- **专家管理界面**：右栏「＋」加/删专家、模型下拉选厂商（DeepSeek / GLM / 千问 / Kimi / MiniMax…）；改动记入 `user-actions.jsonl`，主持人下一轮自动执行，UI 与主持人认知同步。
- **厂商 Logo 头像**：DeepSeek / GLM / Gemini / Claude / Kimi / MiniMax 真实 Logo（base64 内联、离线可用）。
- **知识库（阅览版）**：填路径即列文件；主持人按需读取转交，避免 Token 双倍消耗。
- **回答限制**：专家每轮输出上限 + 最多意见数，会议更省 Token。
- **会议删除**：一键删会议（确认 + 磁盘彻底删除 + 连带清理子代理）。
- **互通开关**：只看当前对话会议 / 看全部。
- **代码收尾**：全量审查清理死代码（host bundle 84.1→80.5 kB），行为不变。

## 新增（V0.2.1 针锋相对评审）

- **红队评审流程**：用户与主持人定下方案后，主持人发起「针锋相对」→ 红队专家只挑毛病 → 评审弹窗（左=问题+方案、右=观点列表）→ 用户点「支持」认定真实缺陷 → 缺陷进入下一轮方案修改。
- 评审记录独立存储（`review.json`）、快照自动弹出评审窗口、标题区 badge + 右栏「分针记录」面板。
- 被删除的专家从拓扑图彻底移除（含连线）。

## 新增（V0.2.2 下一迭代）

- **观点拆分**：专家发言由 LLM 自动拆成 1~3 条独立观点（JSON schema 约束 + 解析失败整条兜底 + quote 原文校验），支持单条「支持」。
- **三态表态**：每个观点 支持 / 驳回 / 取消 互切（`review.setStatus`，旧接口兼容）；已认定数只计「支持」。
- **「针锋相对」协作模式**：设置「默认协作模式」新增第三项，charter 自动附加红队评审协议。
- **健壮性**：进行中的评审禁止静默覆盖；用户表态回写升级为结构化行 id；专家列表已退出置底、快照按 key 去重防同名残留。

## 安装

```sh
dsh plugin --profile web add @huanlin/dsh-plugin-roundtable
```

或从源码：`git clone https://github.com/9931666/dsh-plugin-roundtable && cd dsh-plugin-roundtable && pnpm install && pnpm build && dsh plugin --profile web add .`

## 已知限制

- 专家子代理默认路由（`spawn`）依赖宿主可用的 LLM 路由；跨厂商专家需在加人时显式指定 provider/model。
- 状态为文件级持久化，多进程同时改同一会议不保证一致。
