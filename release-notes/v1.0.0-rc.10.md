# v1.0.0-rc.10 — 侧边栏入口 + 会话标签页开关 + 全局面板

本版只改「从哪里进入圆桌会议」，不动会议协议、拓扑、评审与数据格式。两个入口**默认都开**，老用户升级后能力不减；想收窄的可在设置页关掉任一入口。

## 新增：全局面板（侧边栏主导航）

- 左侧导航栏（与「插件 / 自动化任务」同一组）新增「圆桌会议」入口。
- 点开是一个**只读全局面板**：
  - 顶部「全部工作区 / 某个工作区」范围下拉；
  - 左侧列出会议（名称、进行中/已结束、来源对话短号、轮数、专家数、工作区），按最近发言排序；
  - 右侧直接复用会话里的拓扑视图（拓扑、连线、发言、评审），不是另写一套。
- 列表只读：没有删除/导出/跳转对话，点击只切换右侧视图。

## 新增：两个入口可独立开关

设置 → 圆桌会议 → 「界面入口」：

| 开关 | 默认 | 关掉之后 |
|---|---|---|
| 侧边栏入口 | 开 | 主导航入口与全局面板一起消失，会议数据不受影响 |
| 会话标签页入口 | 开 | 对话页顶部「圆桌会议」标签页隐藏；历史会议仍可从侧边栏面板查看 |

- 两个开关互相独立：可全开、全关、只留一个。
- 保存后**即时生效**（设置页广播 `roundtable:prefs-changed`，客户端注销/重注册入口，无需刷新页面）。
- 偏好字段：`sidebarEntryEnabled`、`conversationTabEnabled`（默认 `true`；旧偏好文件缺字段按开处理）。

## 实现说明（为什么这样做）

- 侧边栏入口注册在宿主文档留给插件的 `sidebar.panellist`，面板注册在同 id 的 `main` keyed 槽；先注册 `main` 再注册入口行，注销反序——否则点行时面板条目缺失，宿主 `selectPanel` 会抛错。
- 两个入口都用 `slots.inject` 等宿主声明就绪后再注册，并保存 disposer：声明未就绪时不会因为一次注册失败拖垮整个 client 插件（标签页、设置页一起消失是最难查的故障）。
- 全局面板不依赖会话上下文，只读插件自己的快照路由（`/state` 不带 `session` 参数即全部工作区），所以不需要 `uiWorkspace` / `layout` 服务。

## 兼容性

- 不传/缺字段时两个入口都开，界面与 rc.9 一致。
- `RoundTableView` 新增可选 `initialMeetingId`，缺省行为不变（仍落到列表第一场）。
- 新增 `main` / `sidebar.panellist` 的 SlotMap 类型镜像；不新增任何 `dsh.client.inject` 依赖。
