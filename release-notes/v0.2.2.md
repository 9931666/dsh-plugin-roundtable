# RoundTable v0.2.2

「A+C+E」方向更新版（v0.2.2，兼容基线 0.1.2-rc.1 不变）。本版由一场针锋相对红队评审驱动：对 v0.2.2「A+C+E」更新计划做了两轮红队攻击（red-zai-a / red-zai-b，均 zai/glm-5.2），用户逐条支持/驳回后按认定的缺陷修订落地。

## 为什么需要本版

v0.2.1 是纯兼容性版本（适配 DSH 0.1.2-rc.1 的 API 变更），功能零新增；同时插件未发布到 npm、无 GitHub Release、市场未上架——几乎没有"正式分发 + 用户反馈"通道。本版打通分发、立住评审口碑、收回真实反馈。

## 变更

### A 分发与可安装性
- **A1 版本号统一为 0.2.2**：`package.json` 0.2.1 → 0.2.2（红队认定的版本号自相矛盾缺陷已修复：v0.2.1 仅为已适配未发布的历史号，本版发布物统一 0.2.2）。
- **A2** GitHub Release v0.2.2 tag（正文抄本文件）。
- **A3** awesome-dsh-plugin 市场上架收尾：英文 README、主图截图、`screenshots.json`、合并 PR（工作区 `awesome-dsh-plugin-fix`）。
- **A4** README 顶部「一分钟安装」+ 自 0.1.1 升级说明（见 `README.md`）。

### C 评审可信度与闭环
- **C1 观点证据分级**：观点拆分 schema 新增 `evidence { kind: 'repro' | 'argument'; text }`——代码/bug 类缺陷要求可复现步骤，设计类缺陷允许论证链（禁止编造伪复现）；前端观点卡按类型展示证据徽标。
- **C2 驳回必填理由**：`ReviewViewpoint` 新增 `rejectReason`；RPC `roundtable/review.setStatus` 在 `status='rejected'` 且理由为空时拒绝；前端驳回先弹理由输入框；user-action 回写附带理由（供主持人修订时对照）。
- **C3 闭环复审终止条件**：`ReviewRecord` 新增 `reviewPass` / `maxReviewPass`（首轮 + 最多复审 2 次 = 3）与 `history[]`（每轮快照）；新工具 `roundtable_finish_review` 落 done 并记录修订说明；复审超上限须用户显式批准（`user_approved_extra_pass`），杜绝无限循环。
- **C4 影响概览**：评审弹窗顶部显示已认定/已驳回/未表态计数；认定数 ≥ 3 时提示"建议重新协商方案"。
- **C5 评审记录导出**：新工具 `roundtable_export_review` 把全部轮次/观点/表态/驳回理由/修订对照渲染为一份 Markdown 交付物。

### E 反馈回路（匿名）
- **E1 轻量反馈弹窗**：会议结束后（status ended）询问一次 1 键有用度（有帮助/一般/没帮助）+ 可选一句"最卡的点"；每会议只问一次（localStorage 记忆），可在设置关闭。
- **E2 「导出为 GitHub issue」**：`roundtable_export_review` 产出的 Markdown 可直接贴入 issue（预填信息见导出物头部）。
- **E3 工作区级 `feedback.jsonl` 匿名聚合**（红队认定的隐私边界缺陷已修复）：只记协作模式/专家 provider/模型/轮数/Token 用量/时间戳 + 用户主动填写的说明；**绝不记录对话内容**；同一会议只保留最新一条；`feedback.list` / `feedback.clear` RPC；首次使用与设置页均明示"收集哪些字段、存于何处、可清空"。
- **E4 设置页「用户反馈」区**：开关（`feedbackEnabled`，默认开）+ 隐私边界说明 + 已收集条目列表 + 一键清空。

### 新工具
| 工具 | 作用 |
| --- | --- |
| `roundtable_finish_review` | 结束当前评审轮（→ done），附修订说明，支持闭环进入下一轮 |
| `roundtable_export_review` | 导出完整评审记录为 Markdown 交付物 |

## 验证

- `tsc` host + client 双端类型检查通过。
- 兼容基线不变：需宿主 0.1.2-rc.1+；其余已知限制与 v0.2.1 相同。

## 安装

```sh
dsh plugin --profile web add @huanlin/dsh-plugin-roundtable
```

或从源码：`git clone https://github.com/9931666/dsh-plugin-roundtable && cd dsh-plugin-roundtable && pnpm install && pnpm build && dsh plugin --profile web add .`

安装后**重启 DSH**、刷新 Web UI。

## 已知限制

- 仅适配 0.1.2-rc.1。
- 其余已知限制与 v0.2.1 相同（第三方模型需显式指定 provider/model；多进程并发写同一会议不保证一致；跨 Session 越权沿用降级校验）。
