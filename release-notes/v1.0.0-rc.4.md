# v1.0.0-rc.4 — 界面视觉优化（轻量）

本版只改界面，不改会议协议、工具语义与数据格式。视觉重量刻意低于针锋的卡片化：
圆桌的主界面是拓扑画布 + 多面板，设置页再加一层带边框的卡片会与针锋产生割裂感。

## 设置页

- **轻分组**：保留「细线 + 组标题」结构，不套卡片；组标题成为细线的下边界，标题到内容收紧 4px。
- **控件统一**：输入 / 下拉 32px 高、8px 圆角、320 宽、次级背景；主按钮 32px、次按钮 28px。
- **面板开关**：从 flex 换行改为等宽网格，七项不再出现"最后一行只剩一个"。
- **列表项**：预设 / 反馈条目去边框，只留浅底（边框曾是视觉重量最大的来源）。
- **图标**：分组标题前加 16×16 内联 SVG 图标（`src/client/icons.tsx`），零依赖、随主题变色。

## 拓扑视图

- **节点放大**：专家节点 68 → 84px（`NODE_RADIUS` 34 → 42，连线端点与环形最小半径同步）；头像 30 → 36px。此前节点在 1900px 宽的画布里显得过小。
- **头像去灰边**：头像不再套一圈 `inset` 灰色圆环 —— 它与节点自身的边框叠成"框里还有框"。
- **主持块对比度**：DeepSeek 主持的黑块上，文字从 `label-secondary`（浅底次要文字色，黑底上读不出来）改为固定白色；块尺寸 96×88 → 108×96。
- **节点名**：显示时去掉专家共有的 `expert-` 前缀并允许两行（`expert-lifecycle` → `lifecycle`）；完整 key 仍由悬停 `title` 提供。
- **连线**：专家间连线从最低对比的边框色改为次级文字色，线宽 1.6、圆端点，浅色底上不再"几乎看不见"。
- **右栏面板**：标题升为正文色 + 字距（此前与说明文字同级），内容内边距 8→10，面板间距 10→12。
- **预算进度条**：90×5px → 100×6px。
